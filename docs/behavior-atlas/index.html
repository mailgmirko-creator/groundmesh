Public-alpha / single-reviewer warning

This release is intentionally small. The underlying claims are sourced and traceable, but independent plural source review has not yet occurred. How to read this alpha

Each case keeps the same chain visible: source → evidence item → atomic claim → pattern assessment → case. Positive evidence and counterevidence remain visible together. Directions use named bands such as mixed or cooperation-supporting; confidence remains qualitative rather than a false-precision number.

Case pages carry review-due dates. After a due date passes, the page automatically displays a stale-data warning and policy requires review, correction, or withdrawal before the assessment is treated as current.
