# GroundMesh Legal Readiness Working Note

Review date: 2026-09-03
Status: Working readiness note, not legal advice

## Boundary

This note is an internal operating guardrail. It is not a legal opinion, not a compliance certification, and not permission to publish sensitive material. A qualified lawyer in the relevant jurisdiction must review any high-risk release, money flow, personal-data processing, broad registration, or contested public case.

## Current Posture

GroundMesh can continue as a public documentation, source, and coordination-prototype repository if it stays inside its current limits:

- static public pages and source files
- synthetic fixtures and non-sensitive examples
- project-level Behavior Atlas pages that use public sources, correction paths, review-due dates, and rollback safeguards
- no broad public registration intake from the static site
- no confidential reporting channel
- no committed secrets or private evidence
- no person subjects, person scoring, enemy labels, motive inference, guilt findings, or autonomous publication

The phrase `internal/` in this public repository is not a confidentiality guarantee. Committed files in a public GitHub repository can be viewed and forked through GitHub functionality. Private evidence, identifying evidence, credentials, and unpublished personal data belong outside the public repo.

## Legal Readiness Gates

Do not expand GroundMesh beyond the current public-docs posture until the relevant gate has passed:

- Public cases: pass `docs/legal/PUBLICATION_GATE.md`, Behavior Atlas validation, privacy/harm review, correction path, review-due date, and rollback drill.
- Registration or Human Mesh intake: define controller/steward, data categories, consent path, withdrawal path, retention, access control, storage location, and breach response before collecting real participant data.
- Donations or money flows: document recipient, tax/accounting posture, no access-conditioned donation language, refund/error handling, and anti-fraud handling before asking the public for funds.
- External validators, press, institutions, or public accusations: prepare a counsel-ready packet first; do not send M2/internal case material or person-related claims without review.
- New CI-assisted public text on matters of public interest: disclose material CI assistance where appropriate and keep human steward responsibility visible.

## Reference Anchors

- GitHub Terms of Service: public repositories grant other users platform permissions to view and fork public content, and uploaders are responsible for rights in content they post. https://docs.github.com/en/site-policy/github-terms/github-terms-of-service
- GitHub licensing guide: public visibility and repository licenses are separate questions. https://docs.github.com/articles/licensing-a-repository
- Open Source Definition: open-source licenses must allow redistribution and derived works, so GroundMesh must not describe TCL-ND-1.0 as OSI open source. https://opensource.org/osd
- EU GDPR: official personal-data regulation reference for EU/EEA processing risk analysis. https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng
- European Commission AI Act page: AI Act obligations apply progressively and include transparency rules relevant to public-interest CI-generated or CI-assisted content. https://digital-strategy.ec.europa.eu/en/policies/regulatory-framework-ai
- Montenegro Agency for Personal Data Protection and Free Access to Information: national supervisory authority reference point for Montenegro data-protection questions. https://www.azlp.me/en/personal-data-protection

## Counsel Packet To Prepare Before Expansion

- current repository URL, license files, `LICENSING.md`, and public pages
- intended operator/entity, country of operation, and audience countries
- data-processing register entries for the exact feature
- sample user-facing copy, consent text, correction path, and withdrawal path
- CI-use disclosure note and human review flow
- source list and evidence handling notes for any public case
- money-flow description for any donation, grant, sponsorship, or payment path
- risk register for privacy, defamation, copyright, platform terms, consumer protection, and safety

## Smallest Safe Next Step

Keep legal readiness as a release gate, not as a claim that GroundMesh is already legally complete. Build only reversible, documented steps until counsel has reviewed the parts that touch personal data, money, public accusations, or institutional reliance.
